# ✈️ Flight Reservation System

A simple Flight Reservation System built using Python.

## 📌 Features

- 👤 Passenger Signup
- 🔐 Passenger Signin
- ✈️ View Available Flights
- 🎫 Book Flight Tickets
- ❌ Cancel Tickets
- 📋 Check Ticket Status
- 🚪 Exit System

## 🛠️ Technologies Used

- Python
- PyCharm

## 🎯 Project Objective

This project was created as a beginner Python project to understand programming concepts and build a simple real-world application.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in PyCharm.
3. Run the Python `.py` file.
4. Follow the instructions displayed in the terminal.
